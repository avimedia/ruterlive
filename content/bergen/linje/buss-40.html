40-bussen går mellom Bergen busstasjon og Storavatnet terminal via Olsvik og Godvik. Turen har 19–20 stopp og tar rundt en halvtime. Ut fra sentrum står det «Olsvik» på skiltet, selv om bussen kjører helt til Storavatnet.

Fra Bergen busstasjon går bussen via Olav Kyrres gate og Møhlenpris, og så vestover til Lyngbø rv. 555. Derfra går den opp via Rishaugen, Brønndalen og Skjenlien til Fredheim Olsvik og Olsvikåsen, og videre via Olsvikfjellet, Olsvikskiftet og Olsvikveien. Etter Gjerdingsskjenet går den via Leirvikneset og Leirvikflaten til Øvre Godvik i Leirvikåsen og Godviksvingene, før den ender på Storavatnet terminal.

Mot sentrum stopper den på Frieda Fasmer rv. 555 og Lyngbø rv. 555, og så på Møhlenpris og Festplassen før busstasjonen.

På hverdager går 40-eren omtrent hvert 20. minutt midt på dagen og hvert 15. minutt om ettermiddagen. Om kvelden er det 20–30 minutter mellom avgangene. På Storavatnet terminal kan du bytte til 20, som går via Loddefjord og Laksevåg til Haukeland og Nesttun. På Bergen busstasjon stopper Bybanen linje 1 og 2.
