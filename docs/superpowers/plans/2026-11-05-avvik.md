# Avvik for hele landet – implementasjonsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Avvik (SIRI SX) fra hele Norge på kartet, i tavla, i popupen, på linje- og holdeplassider og på `/avvik`.

**Architecture:** Én servermodul henter `situations` for hele landet fra Entur Vehicles-API hvert 2. minutt, normaliserer og indekserer. `/api/situations?region=` gir klienten regionens avvik; serverrendrede sider slår opp direkte i modulen. Ingen region er hardkodet: kodeområder per region står i `shared/regions.js`.

**Tech Stack:** Node 20 + Express, plain JS + Leaflet (Vite), `node:test`.

**Spec:** `docs/superpowers/specs/2026-11-05-avvik-design.md`

## Global Constraints

- Hver Entur-forespørsel sender `ET-Client-Name: ruterlive-web`. Avvik hentes fra `https://api.entur.io/realtime/v2/vehicles/graphql`, aldri fra Journey Planner.
- Én felles henting for alle brukere, hvert 2. minutt; ingen kall mot Entur per bruker.
- Kommentarer, logg og UI-tekst på norsk. Tekstregler: kort, uten standardinnledninger, fyllfraser, oppsummering eller oppdiktet forfatter.
- All tekst fra Entur/operatører escapes (`escapeHtml` på server, `textContent`/escape på klient). Lenker fra Entur bare `http:`/`https:`.
- Kartsidene (`/`, `/bergen`) laster aldri AdSense. `/avvik` har annonser (`renderPage`, `ads: true`) og indekseres.
- Forsidetittel: «Sanntidskart for kollektivtrafikken i Oslo og Bergen | livetrafikk.no».
- Topp-RSS < 420 MB (`npm run memcheck -- --regions oslo,bergen`). Ingen push uten brukerens ja.

## Review Focus

1. Avvik med flere `validityPeriods`, åpen slutt (`endTime` null) eller start om > 24 t: vises bare når en periode gjelder nå eller starter innen 24 t (Task 1).
2. Avvik som bare har engelsk tekst, eller tekst med `language: null`: norsk/null foretrekkes, engelsk som reserve, aldri tomt kort (Task 1).
3. Operatørtekst med HTML (`<script>`, `<a onclick>`) eller `javascript:`-lenker: vises som tekst, lenken droppes (Task 1, 3, 5).
4. Entur nede over tid: forrige liste i inntil 15 min, deretter ingen avvik og en tydelig melding på `/avvik`, aldri krasj (Task 2, 3).
5. Avvik som gjelder en holdeplass via `NSR:StopPlace` mens tavla kjenner quay-ID-er (og omvendt): vises i tavla og på holdeplassiden (Task 1, 4, 6).
